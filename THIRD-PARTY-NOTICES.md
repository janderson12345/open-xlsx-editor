## The Office Open XML standard

The file format follows the Office Open XML standard, ECMA-376 (copyright Ecma International, which publishes it free
of charge for anyone to use). A few small tables in the code come from it: the built-in number formats, and the
legacy palette that `indexed` colours count in.

## Fonts and Microsoft material

- **No Microsoft material.** The repository and the package contain no Microsoft code, templates, workbooks or
  fonts. Excel's behaviour was measured by running Excel and comparing its output; what the code holds are the rules
  and numbers found that way.
- **Font measurements.** `src/engine/metrics.js` holds measurements of common fonts (ascent, descent and line gap per
  em). They are facts about the fonts, not any part of them.
- **AutoCorrect.** The AutoCorrect list (`src/editor/autocorrect-list.js`) is 39 common corrections, such as "teh"
  to "the" and "(c)" to "©", as Excel makes them.
- **open-metric-fonts.** The open-metric-fonts fonts (https://github.com/open-metric-fonts/open-metric-fonts, SIL Open
  Font License 1.1) are not in this package. A host page that wants Aptos's metric twins serves its own copy, and
  the editor loads them from there (README, Fonts). `src/editor/omffonts.js` lists, from that project's
  `morrow-sans` package, its font files and the characters each holds.

The test workbooks in `test/fixtures` are generated by the scripts beside them with made-up data. The workbooks the
layout was measured against are private and not in the repository.
