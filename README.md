# open-xlsx-editor

Open and edit .xlsx files in the browser. Plain JavaScript, no server, no Office.

Not started yet. Sister project of open-docx-editor, built the same way.

- `LESSONS.md`: what the Word editor taught, and what to set up from day one.
- `CLAUDE.md`: the rules for working on this code.
- `docs/REUSE.md`: which Word editor modules carry over, which change, and what is new.
